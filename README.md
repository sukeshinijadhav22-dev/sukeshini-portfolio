# Sales Performance & Revenue Analytics

## Overview
Analyzes sales transactions to identify revenue trends, top products, regional performance and monthly KPIs.

## Skills Demonstrated
Python, Pandas, NumPy, Matplotlib, Seaborn, EDA, KPI analysis

## Project Workflow
1. Load and validate the dataset.
2. Clean and prepare analytical variables.
3. Perform exploratory data analysis (EDA).
4. Calculate business/operational KPIs.
5. Group and segment data to identify patterns.
6. Create visualizations and communicate insights.

## Files
- `analysis.py` — main analysis script
- `data/sales_data.csv` — synthetic dataset
- `requirements.txt` — Python dependencies

## How to Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Note
The dataset is synthetic and created for portfolio/learning purposes. It does not contain real customer, employee or patient information.
